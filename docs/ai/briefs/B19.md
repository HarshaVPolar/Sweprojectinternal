## Contract (docs/design/build-contract.md)

- Specification: build contract section 7.2 (token_store.py row); build contract section 5 (oauth_token); docs/adr/005-oauth-and-token-storage.md; docs/design/security.md (threat T-07).
- TokenStore(conn, data_dir, clock, passphrase_provider=None, keyring_module=None). save(account, refresh_token, scopes) -> None; load() -> StoredToken or None; delete() -> None. StoredToken is a frozen dataclass (account, refresh_token with repr=False, scopes, issued_at). Primary storage: keyring service "ytmcp", username "default", value a JSON document. The oauth_token row holds only metadata: account_hash (SHA-256 of the account), scopes joined by spaces, keyring_ref ("keyring" or "file"), issued_at and expires_at (issued_at plus 7 days).
- Fallback when the keyring is unusable (a NoKeyringError or any KeyringError on a probe): an encrypted file data_dir/token.enc with mode 0600 on POSIX, Fernet with a key derived by scrypt (n=2**15, r=8, p=1, random 16-byte salt stored in the file header) from a passphrase taken from passphrase_provider(), by default the environment variable YTMCP_TOKEN_PASSPHRASE. Without a passphrase raise AuthRequired with a message naming YTMCP_TOKEN_PASSPHRASE; a wrong passphrase or a corrupt file raises ReauthRequired. Token values never appear in logs, exceptions, reprs or the database.

## Layer rules (docs/design/build-contract.md section 2)

- infra: imports sqlite3, keyring, cryptography, models, errors, config and ytmcp.infra.clock; only this module imports keyring and cryptography.

## Acceptance tests (write first)

- tests/security/test_token_store.py with an in-memory keyring backend registered through keyring.set_keyring and a temporary database: save, load and delete round trip; metadata row content and expiry of 7 days; no secret in any database column.
- File fallback with an injected passphrase: round trip; the file does not contain the token in plain text; wrong passphrase raises ReauthRequired; missing passphrase raises AuthRequired; corrupt file raises ReauthRequired; POSIX mode 0600 (skip on Windows).
- The token value is absent from repr, str, exception messages and captured log output.
