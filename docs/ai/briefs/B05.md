## Contract (docs/design/build-contract.md)

- Specification: build contract section 9 (envelope, tools, untrusted text); docs/api/tools.md section 3.8 (get_quota_status); build contract section 2 (server.py is the composition root).
- Built in Stage 2: build_server, create_provider, stub_quota_status, TOOL_REGISTRARS, ToolDeps and render_result. Pattern for every later tool: a module with register(mcp, deps) -> None, a new field in ToolDeps and an entry in TOOL_REGISTRARS in server.py.

## Layer rules (docs/design/build-contract.md section 2)

- server.py may import everything.
- Tool modules import only services, models, errors and ytmcp.tools; the single exception for domain.sanitiser is added to pyproject.toml by the first tool that needs it.
- Stdout belongs to the MCP protocol, so nothing else may print.

## Acceptance tests (write first)

- Built in Stage 2; tests/unit/test_server.py (stub status, provider factory, one registered tool with its annotations, main and configuration errors), tests/system/test_server_boot.py (a real client lists the tool, calls it and receives the envelope; a bad configuration exits with code 2) and tests/unit/test_smoke.py.

## Forbidden

New dependencies, HTTP outside providers/live.py, reading .env or token files, weakening tests, changing files outside the list, inventing API fields that are not present in tests/fixtures.

## Output

Small, focused change, traceability row.
