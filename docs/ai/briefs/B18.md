## Contract (docs/design/build-contract.md)

- Specification: build contract section 2 (the layer table is what the test enforces); docs/design/architecture.md section 2 and docs/design/architecture.md section 8.
- tests/test_layers.py parses every .py file below src/ytmcp with the ast module, collects the imports of ytmcp modules and asserts the import table of build contract section 2, including the single sanitiser exception for tools and resources. It also asserts source rules: httpx is imported only in providers/live.py; google_auth_oauthlib and google.auth are imported only in infra/oauth.py; keyring and cryptography only in infra/token_store.py; create_playlist and add_playlist_item are called only in services/playlist_service.py (definitions in providers are allowed); the string approval_state is written only in services/confirmation_gate.py.
- .github/workflows/ci.yml: after the existing test step add a step python -m coverage report --include="src/ytmcp/domain/*" --fail-under=90 (the domain gate; no second test run); the 3-OS matrix already exists.
- .github/workflows/mutation.yml: runs weekly (cron) and on workflow_dispatch on ubuntu-latest, installs the project with the dev and mutation extras, runs python -m mutmut run and uploads the mutmut results as an artifact; it does not fail the build on surviving mutants. pyproject.toml gets a [tool.mutmut] section naming the mutated files: the files of src/ytmcp/domain and services/quota_guard.py.
- scripts/check_quota_budget.py: options --db (path of the SQLite file), --max (default 500) and --day (default the current Pacific-time day); prints "used <n> of <max> units on <day>"; exit code 0 when the sum of quota_ledger units for that day is at most max, 1 when it is above, 2 for a missing database or any other error.

## Layer rules (docs/design/build-contract.md section 2)

- tests and workflow files are outside the package.
- test_layers.py may import ytmcp but must not import anything that opens a network connection.
- pyproject.toml is changed only for the [tool.mutmut] section.

## Acceptance tests (write first)

- tests/test_layers.py passes on the current tree and fails when an illegal import is added (prove it with two small synthetic source trees written to tmp_path and checked by the same helper functions).
- tests/unit/test_check_quota_budget.py: a temporary SQLite file with a minimal quota_ledger table holding 400 units gives exit 0 and the expected text; 501 units gives 1; a missing file gives 2; rows of another day are ignored.
- The domain coverage gate command works locally after a normal pytest run with coverage.

## Forbidden

New dependencies, HTTP outside providers/live.py, reading .env or token files, weakening tests, changing files outside the list, inventing API fields that are not present in tests/fixtures.

## Output

Small, focused change, traceability row.
