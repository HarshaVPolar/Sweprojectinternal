## Contract (docs/design/build-contract.md)

- Specification: build contract section 5 (audit_log); build contract section 7.2 (audit_log.py row); SRS FR-5.14.
- AuditLog(conn, clock): write(event, proposal_id, actor) -> None and list(proposal_id=None) -> list[AuditEntry] (a frozen dataclass with audit_id, event, proposal_id, actor, created_at). Allowed events: confirm, create, reject, resume, fail. Allowed actors: user_confirm, system. proposal_id must match the lower-case UUID4 pattern. Anything else raises ValueError, so no free text or personal data can be stored.
