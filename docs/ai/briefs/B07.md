## Contract (docs/design/build-contract.md)

- Specification: build contract section 1 (conventions) and build contract section 2 (logging_setup.py may import models, errors and config).
- configure_logging(level="INFO", stream=None) -> None installs one handler that writes one JSON object per line to the stream, by default sys.stderr and never stdout. Fields: ts (UTC ISO 8601 ending in Z), level, logger, message, and, when set, request_id, tool, outcome, units.
- bind_request(request_id, tool) is a context manager based on contextvars; set_outcome(outcome, units) updates the current context; get_request_id() returns the current id or None.
- redact(text) -> str replaces: e-mail addresses by redacted@example.invalid; the prefixes ya29. and 1//0 tokens, API keys (AIza plus 35 characters), Bearer tokens of 20 or more characters and 21-digit account IDs by REDACTED; and the values of fields named access_token, refresh_token, client_secret, authorization and api_key by REDACTED. RedactingFilter applies redact to the message, to string arguments, to string values of extra fields (also nested) and to formatted exception text.

## Layer rules (docs/design/build-contract.md section 2)

- logging_setup.py uses the standard library and ytmcp.config types only; it must not import infra, providers, services or tools.

## Acceptance tests (write first)

- tests/unit/test_logging_redaction.py: every pattern above is redacted in the message, the arguments, extra fields, nested dictionaries and exception traces.
- Ordinary channel IDs and video IDs are not redacted.
- Output is one valid JSON object per line with the listed fields.
- Nothing is written to stdout.
- Calling configure_logging twice does not duplicate handlers.
- bind_request adds request_id and tool inside the block and not outside; level filtering works; Unicode text survives.

New dependencies, HTTP outside providers/live.py, reading .env or token files, weakening tests, changing files outside the list, inventing API fields that are not present in tests/fixtures.
